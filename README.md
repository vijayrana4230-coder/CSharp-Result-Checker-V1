# C# Result Checker - Version 1

## About the Project
This is a simple console-based Result Checker
developed using C#.

The program calculates students' marks and displays
the result based on the program's logic.

## Features
- Takes student marks as input
- Calculates total marks
- Calculates percentage
- Displays the result

## Technologies Used
- C#
- .NET
- Visual Studio

- Conditional statements
- User input and output
